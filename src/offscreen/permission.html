Allow the microphone for VoiceType

VoiceType records inside the extension, so Chrome asks once for microphone access for VoiceType itself, not for each site.

When Chrome asks, choose Allow while visiting the site. An "Allow this time" answer can expire when this tab closes, and Chrome would ask again on the next dictation.

Waiting for your answer in the Chrome prompt.

To change this later, open chrome://settings/content/microphone, find VoiceType under "Not allowed to use your microphone" and set it to Allow. Then press REC again.
