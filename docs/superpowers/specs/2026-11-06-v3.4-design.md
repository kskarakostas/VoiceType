# VoiceType 3.4 Design Spec

Prepared 2026-11-06 for K. S. Karakostas. Extends `docs/superpowers/specs/2026-11-06-v3.3-design.md` and the specs it names, whose decisions V1 to V67, anti-goals and global constraints stay in force except where this spec says otherwise. Sources: the code at `a0d94a3` (v3.3.0) and the mockup K. S. Karakostas reviewed on 2026-11-06.

Tags: **VERIFIED** (read in the code), **DECIDED** (K. S. Karakostas, 2026-11-06), **PROPOSED** (Atlas's call, changed only with K. S. Karakostas's approval).

## 1. Intent

K. S. Karakostas finds the settings too many clicks apart, no longer likes the icon, and wants the popup more pleasing and compact. Copy last only reaches the newest dictation. 3.4 is a tidy-up release: one Settings page, a new icon, a shorter popup, and a pick of recent dictations.

**Goals**
- The seven Settings pages become one page with dividers.
- A new icon everywhere VoiceType shows one.
- A shorter popup: one row for provider and mode, one line for this site, four numbers for today.
- A way to copy any of the last 5 dictations from the popup.

**Non-goals:** merging Home, Modes, Dictionary or History; a search box in settings; a new provider or mode feature; a history view in the popup with more than 5 entries, times or sites; new settings.

**Anti-goals** (3.4 fails if any of these happens): the 3.0 to 3.3 lists, and:
- A link that works in 3.3 stops working: `#settings/provider`, the popup's Add API key, Welcome's links, or a bookmark to any of the seven hashes.
- A control loses its label, keyboard order or focus ring in the move.
- The popup shows dictated text before the arrow is pressed.
- The icon cannot be told apart at 16 px on a light or a dark toolbar.
- A new permission, a new runtime dependency, or a stored field.

## 3. The icon's shapes

In a 64 by 64 box. Fill `#4f46e5` for the square, white for the rest.

| Part | Shape |
|---|---|
| Square | `rect` 64 by 64, `rx` 14 |
| Microphone | `rect` x 17, y 12, 15 by 26, `rx` 7.5 |
| Stand | path `M11 30a13.5 13.5 0 0 0 27 0M24.5 44v7`, stroke 4.5, round caps. Left out of `icon16.svg` |
| Cursor | path `M48 14v36`, stroke 5, round caps |

The three white parts sit in one group shifted 2.4 units right, `translate(2.4 0)`, so the drawing is centred in the square (its content spans x 8.75 to 50.5 before the shift). The square does not move. The coordinates above are those inside the group.

## 4. Testing

- Unit: `parseRoute` for each old hash; `showRoute` shows one Settings section and focuses the right heading; sidebar `aria-current`; popup Today numbers and `m:ss`; recent list closed at open, 5 at most, the whole text copied, hidden below 2 entries and with history off, emptied by a clear.
- e2e on Chromium 153 and Chrome 140: each old hash lands on its part; Add API key lands on Provider; a settings page at 380 px has no sideways scroll; forced colours on the rule and the arrow; popup height below the 3.3 popup's; a long site name stays on one line.
- Existing tests that open `#settings/…` keep passing with no change to their hash.
- Manual, K. S. Karakostas: the icon on a light and a dark toolbar, and in a tab; the merged page by feel; the popup on a real site and on a page VoiceType cannot run on.
