# VoiceType 3.0 L5 Pill styles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three pill styles (Dot, Pill, Minimal) chosen on an Appearance page, Minimal on hidden sites, and a top-frame indicator when a recording frame is out of view.

**Architecture:** One `Pill` class renders every style from a `data-style` on its root; the controller picks the presentation (a hidden site always gets Minimal). A frame's `Pill` watches its own indicator with `IntersectionObserver`; when it goes out of sight the service worker tells frame 0, which shows a second, non-interactive `Pill` in Minimal.

**Tech Stack:** Chrome MV3 (minimum Chrome 140), plain JavaScript with JSDoc, esbuild, Vitest with jsdom, Playwright with bundled Chromium.

**Spec:** `docs/superpowers/specs/2026-11-03-v3-design.md` (sections 2 V5, V10, V19; 5; 6.6). Master plan: `docs/superpowers/plans/2026-11-03-v3-master.md` (L5 row). Deferred input: `docs/superpowers/plans/2026-11-03-v3-l3-ledger.md`, "For L5".

## Decisions this plan applies

K. S. Karakostas, 2026-11-04 (AskUserQuestion):
1. **Swap.** Today's idle pill is already a 16 px dot, so spec 6.6 made Pill and Dot near-duplicates. Dot is now today's look and behaviour exactly, and it is the default. Pill is the full bar shown at idle, opt-in. This replaces 6.6's Dot text (8 to 10 px, a button, expands on every status). Nobody's look changes.
2. **Mirror when unseen.** A frame's recording indicator out of the top viewport brings up the Minimal indicator at the bottom centre of frame 0, for recording and processing only. Statuses stay in the frame.

PROPOSED (controller, within the spec):
- A hidden site uses Minimal whatever `pillStyle` says; spec V10 unchanged.
- The style is read from `settings.pillStyle`, which `toPublicSettings` already sends, and applies live: a change during a recording moves the indicator, and it keeps recording.
- `MINI_SIZE` is 92 x 28 px. Bottom gap is `CORNER_MARGIN` (16 px).
- Reduced motion: level bars keep fixed heights, the elapsed time still counts (text, not motion).
- Processing shows the dots icon in the indicator, with no time.
- Out of sight means under half of the indicator is inside the top viewport (`SIGHT_THRESHOLD = 0.5`).
- The mirror is a second `Pill` instance, so frame 0's own pill keeps working beside it. It expires after `PROCESSING_TIMEOUT_MS` without a message, in case the worker died.
- Level messages also go to frame 0 while mirrored: live bars, and they keep that timer fresh.
- Card order on the page: Pill, Dot, Minimal (spec order). Dot carries a "Default" tag.
- `visibility: hidden` on an iframe is not detected (`IntersectionObserver` still reports it); goes to the ledger as deferred.
- L3's deferred `settle` item (an offscreen idle pill coming back at an unfocused field) is fixed here.

## Review Focus

1. A recording that ends on any path (cancel, frame removed, frame navigated, tab closed, failure, auto-stop into a result) with the mirror up: a stale "recording" indicator must not stay. Task 3, table of exits.
2. The style changes while a menu is open, while recording, or while a click-to-copy status is pinned: the menu closes on Minimal, the recording stays indicated, the transcript stays reachable. Tasks 1 and 2.
3. A frame too small for the indicator, or narrower than a long status: clamped inside the frame, and the frame reports out of sight so the mirror covers it. Tasks 1 and 3.
4. Clicks in Minimal: a page button under the indicator or under a plain status gets the click; a clickable status takes it without moving focus. Task 5.
5. Page CSS aimed at the host (`voicetype-host { display: none !important }`) and a right-to-left page: every style looks and works the same. Task 5.
