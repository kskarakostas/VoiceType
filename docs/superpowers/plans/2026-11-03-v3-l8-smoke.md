# VoiceType 3.2 smoke checklist (for K. S. Karakostas)

Branch `v3.2`, still version 3.1.0: the bump comes after your results. Covers what lane L8 added or changed, then one list of every manual row still open from the 3.0 and 3.1 files. Every harness row below was run by Atlas.

The Run column says who has it: **H** a harness ran it (result in the row), **M** a person has to. Your part is every M row. Fill Result with pass, fail (with the exact on-screen text) or n/a. Needs a working key and a real microphone.

Build, then reload VoiceType on `chrome://extensions` and reload any open page:

```bash
npm run build
```

Fixture pages, in a second terminal:

```bash
node test/fixtures/serve.mjs
```

`http://localhost:8765/fields.html` has a text field `#text`, a textarea, a password field and frames. The dictation hotkey is Ctrl+Shift+Space, the edit hotkey Ctrl+Shift+E.
