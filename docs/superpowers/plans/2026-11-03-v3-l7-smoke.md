# VoiceType 3.1 smoke checklist (for K. S. Karakostas)

Branch `v3.1`, version 3.1.0. Covers what lane L7 added or changed. The 3.0 list stays in `docs/superpowers/plans/2026-11-03-v3-release-smoke.md`; its harness rows were rerun on this build and its manual rows were never reported back, so they are open too.

The Run column says who has it: **H** a harness ran it (results at the end), **M** a person has to. Your part is every M row. Fill Result with pass, fail (with the exact on-screen text) or n/a. Needs Chrome 140 or newer, a working key and a real microphone.

Build, then reload VoiceType on `chrome://extensions`, or Load unpacked on `dist/` for the first-install rows:

```bash
npm run build
```

Reload any open page after reloading the extension. Fixture pages, in a second terminal:

```bash
node test/fixtures/serve.mjs
```

`http://localhost:8765/fields.html` has a text field `#text`, a textarea, a password field and frames. The hotkey is Ctrl+Shift+Space.
