# VoiceType 3.0 lane L0 smoke checklist (for K. S. Karakostas)

Branch `v3`, still version 2.2.0 (only L6 bumps the version). Checks the L0 deliverables: schema v3 migration, the settings page in a tab, the quick-panel popup. Needs Chrome 140 or newer and one working key. Note each item as pass, fail (with the exact on-screen text) or n/a, and put the result in the L1 kickoff's SMOKE line.

Build first:

```bash
npm test
npm run build
npm run test:e2e
```

`npm run test:e2e` now also runs `test/e2e/settings.spec.js` (route reuse, close-after-one-second on Speech and Provider, pill sync, Reset).

## 0. Before you reload: the upgrade is one way
The upgrade rewrites your stored settings as v3 on first read: `keywords` moves into `dictionary.any`. If you later load 2.2.0 again on the same profile, it keeps keys and modes but shows an empty vocabulary. Copy your vocabulary list somewhere first if you may roll back.

## 1. Upgrade in place (v2 store to v3)
- With 2.2.0 loaded from this folder and your real settings (keys, a custom mode, vocabulary, a changed hotkey), click the reload icon on the VoiceType card in chrome://extensions after `npm run build`.
- Open the settings page (section 2). Provider shows your key masked (`sk-p…xxxx (saved)`), Modes lists your custom mode after the built-ins, Settings, Speech shows your vocabulary terms with the right count ("N of 100 terms"), Recording shows your hotkey and limits.
- Dictate once with a vocabulary word: it is still recognized (the dictionary reaches the provider).

## 2. Opening the settings page
- chrome://extensions, VoiceType, Details, "Extension options": the settings page opens in a tab at `#home` with the placeholder "Coming in a later update.".
- Reload the tab on `#settings/recording`: it stays on Recording.
- Type `#nope` after `options.html` in the address bar: Home shows.
- The sidebar lists Home, Modes, Dictionary, then Settings: Provider, Recording, Speech, Sites, Appearance, Sound and clipboard, Usage and data; the footer shows "Version 2.2.0", "by K. S. Karakostas", GitHub and Privacy (both open in a new tab).
- Dictionary, Sites, Appearance, Sound and clipboard show their one-line placeholder; Dictionary's links to Settings, Speech.
- Narrow the window under about 720 px: the sidebar stacks above the content and nothing scrolls sideways.

## 3. Quick-panel popup (toolbar icon)
- The popup shows, top to bottom: status ("Ready" with a key), Provider (OpenAI / Gemini), Mode select, This site ("Site controls are coming in a later update."), Today (sessions and cost), Open settings. Width as before.
- With no settings tab open, click Open settings: a new tab at `#home`; the popup closes.
- Navigate that tab to Modes. Open the popup again and click Open settings: no new tab; the existing tab comes to the front and stays on Modes (no reload: anything half typed there is still there).
- Put the settings tab in a second window, focus the first window, open the popup there and click Open settings: the second window comes to the front with the tab active.
- Switch the provider to one with no key: the status changes to an "Add API key" button. Click it: the open settings tab (reused, not a new one) shows Provider. Switch the provider back.
- Change the mode in the popup's select: the toast "Mode: <name>" shows, and the pill on any open page shows the new mode within a second.
- Modes on the settings page: open a mode's editor; its title ("Edit mode") now uses the card-heading style (uppercase, grey). Note whether that reads well; 2.2 showed it as dark bold text.

## 4. Every 2.2 setting persists from the page
For each item: change it, wait one second, close the settings tab, reopen it: the change is there.
- Provider: switch provider; paste a key into the empty field (Test says it works; Clear empties it at once, toast "Key cleared"; paste it back).
- Recording: minimum and maximum length, silence auto-stop, hotkey (click, press a new chord; Esc cancels while armed).
- Speech: spoken languages (Auto clears the others); vocabulary (type a few terms, one per line).
- Modes: select a mode; edit a built-in mode's prompt; create a custom mode (Create once), edit it, delete it.
- Usage and data: Refresh fills the table; Clear history needs two clicks and empties it.

## 5. Close one second after typing (anti-goal)
- Speech: type a new vocabulary term without leaving the field, count to two, close the tab with Ctrl+W. Reopen: the term is there.
- Provider: paste a key and close the tab the same way. Reopen: the key shows masked.
- Best effort only (not a pass criterion, note what you see): type and close at once, under half a second.

## 6. Two places editing at once
- Open the settings page on Recording. In the popup, change the mode. Back on the page, change the maximum length. Reopen the popup: the mode you chose in the popup is still selected (the page saved only the maximum length).
- Open two settings tabs. In tab A, start typing a vocabulary term; in tab B change the provider. Tab A keeps your half-typed text; tab A's provider control updates to B's choice.

## 7. Reset to defaults
- On Settings, Usage and data, the Reset card has its own heading; the hint reads "Resets modes and prompts, the Translate target language, recording limits, silence auto-stop, the hotkey, the pill style, sounds and always-copy. Custom modes are deleted, and site rules that use one lose their mode (a rule with no other setting is removed). Keeps your API keys, provider, spoken languages, dictionary and site rules."
- Click Reset to defaults: the button reads "Click again to reset. Custom modes will be deleted.". Click again: toast "Settings reset".
- Kept: keys, provider, spoken languages, vocabulary. Reset: modes (custom ones gone), the Translate target language, recording limits, silence auto-stop, hotkey back to Ctrl+Shift+Space.

## 8. Look and keyboard
- Light and dark (OS setting): both the popup and the settings page follow it; text is readable on every surface.
- Tab through the settings page from the top: focus rings are visible on every control, the order follows the screen, and choosing a sidebar link moves focus to that page's heading.

## 9. 2.2 regressions (quick pass)
- On a normal page: tap the hotkey to dictate into a textarea; hold it to talk; dictate into a frame on `http://localhost:8765/fields.html` (`node test/fixtures/serve.mjs`); the password field refuses with "VoiceType does not record in password fields."; the cost shows after "Done" and Today in the popup counts the session.
