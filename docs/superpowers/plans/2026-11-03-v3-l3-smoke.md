# VoiceType 3.0 lane L3 smoke checklist (for K. S. Karakostas)

Branch `v3`, still version 2.2.0 (only L6 bumps the version). Checks the L3 deliverables: hiding the pill on a site, a mode per site, the popup's This site block and the Sites page. Needs Chrome 140 or newer and one working key. Note each item as pass, fail (with the exact on-screen text) or n/a, and put the result in the L4 kickoff's SMOKE line.

Build first, then click the reload icon on the VoiceType card in chrome://extensions:

```bash
npm test
npm run build
npm run test:e2e
```

Reload any open page you test on after reloading the extension.

## 1. Hide the pill from the popup
- Open a normal site, click into a text field: the pill shows.
- Open the popup. This site shows the host without `www.`. Check Hide pill: within a second the pill goes, without a reload.
- Click into other fields on that page: no pill. Reload the page and click a field: no pill, and none flashes.
- Open a page of another site: the pill shows there as usual.

## 2. The hotkey still records on a hidden site
- On the hidden site, focus a field and tap the hotkey: today's pill appears while recording. Speak, tap again: the text lands in the field, the Done status shows, and the pill then goes.
- Hold the hotkey, speak, release: same result.
- Press the hotkey in a password field: the refusal shows, nothing records.
- Dictate, then move focus to another field while it processes: the text goes to the clipboard with its status, and the pill then goes.

- Focus a field, scroll it out of view, press the hotkey: the pill appears in the bottom-right corner while recording, and returns to the field if you scroll back. Same on a normal site.

## 3. Frames on a hidden site
- Run `node test/fixtures/serve.mjs`, open `http://localhost:8765/fields.html` and hide `localhost` in the popup. Click into the fields of the same-origin and cross-origin frames: no pill.
- The hotkey records there, with the pill inside the frame.

## 4. A mode for a site
- In the popup, on a site, set Mode on this site to Email. Dictate there: the text comes back as an email. The popup's Mode select still shows your global mode.
- On another site, dictation uses the global mode.
- With that site's pill open: the mode button shows Email, the menu lists Use active mode first, and Email reads This site.
- Pick Translate in the pill: the site's mode changes, the global mode does not (check the popup). Translate's target language section shows.
- Pick Use active mode: the marking goes, and the rule is gone from Settings, Sites if it did not also hide the pill.
- A site with Hide pill only: the pill's mode pick (visible while recording) changes the global mode.

## 5. A deleted mode
- Create a custom mode, set it as a site's mode, delete it in Modes. The site falls back to the active mode; the Sites row is gone unless it hides the pill.

## 6. Not available pages
- Open the popup on `chrome://extensions`, on the Web Store, on a `file:` page and on the new tab page: This site reads "Not available on this page", with no controls.

## 7. Settings, Sites
- Add `https://www.example.com/some/page` with Hide pill on: the row reads `example.com`, the field empties, Hide pill returns to on.
- Add `example.com` again: refused with "example.com already has a rule."
- Type `not a host`, press Enter: refused with the hint; the text stays.
- Turn Hide pill off and leave Use active mode, press Add: refused with "Turn on Hide pill or choose a mode."
- Type a host, do not press Add, close the tab, reopen: no rule was added.
- In a row, change the mode: an open tab of that site follows within a second.
- Turn Hide pill off on a row with no mode: the row goes and focus moves sensibly.
- Remove a row: the toast names the host, and an open tab of that site shows its pill again.
- Shrink the window to phone width, light and dark: rows stack, no sideways scroll, focus rings visible.

## 8. Two pages at once
- With the Sites page and the popup open on the same site, change the rule in the popup: the row follows.
- With an old settings tab left open, add a rule in a new tab, then change a Recording setting in the old tab: the rule survives.

## 9. Reset
- Settings, Usage and data, Reset to defaults: site rules stay; a rule using a custom mode loses that mode as the hint says.

## 10. Back and prerender
- On a site, go from page 1 to page 2 of the same site. Hide the pill in the popup on page 2, press Back, click a field: no pill.
- Undo the rule on page 2, press Back, click a field: the pill shows.
- Chrome may prerender a page you type often in the address bar. Hide a site you visit daily, type its address from another site, click a field: no pill. Do the reverse from a hidden site to a normal one: the pill shows.

## 11. The pill's mode button (fixed in this lane)
- On a normal site, hover the idle pill and click the emoji mode button anywhere on it: the menu opens. Before this lane the left part of the button did nothing.

Also check: a real action popup (automation drives it through a page in a tab), a screen reader on the Sites table, the pill's first appearance on a page after Chrome has been idle (the first idle pill now waits for one answer from the service worker).
