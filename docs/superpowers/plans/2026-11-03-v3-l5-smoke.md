# VoiceType 3.0 lane L5 smoke checklist (for K. S. Karakostas)

Branch `v3`, still version 2.2.0 (only L6 bumps the version). Checks the L5 deliverables: the three pill styles, the Appearance page, hidden sites on Minimal and the top frame indicator for a recording in a frame out of sight. Needs Chrome 140 or newer, a working API key, speakers and a real microphone. Fill the Result column with pass, fail (with the exact on-screen text) or n/a, and put the result in the L6 kickoff's SMOKE line.

Build first, then click the reload icon on the VoiceType card in chrome://extensions:

```bash
npm test
npm run build
npm run test:e2e
```

Start the fixture pages in a second terminal. They stay up for the whole checklist:

```bash
node test/fixtures/serve.mjs
```

Reload any open page you test on after reloading the extension. Fixture pages:

- `http://localhost:8765/fields.html`: text field (`input type=text`), textarea, contenteditable, `input type=password`, open shadow root input, same-origin iframe, cross-origin iframe.
- `http://localhost:8765/hostile.html`: a page rule tries to hide and shrink the pill host, and sets 30 px text on everything.
- `http://localhost:8765/rtl.html`: a right-to-left page.

The hotkey is the default Ctrl+Shift+Space unless you changed it. To change the style, use Settings, Appearance. "Hide pill" is the checkbox in the toolbar popup on that site.
