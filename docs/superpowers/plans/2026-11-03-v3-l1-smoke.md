# VoiceType 3.0 lane L1 smoke checklist (for K. S. Karakostas)

Branch `v3`, still version 2.2.0 (only L6 bumps the version). Checks the L1 deliverables: word counts in the usage log and the Home dashboard. Needs Chrome 140 or newer and one working key. Note each item as pass, fail (with the exact on-screen text) or n/a, and put the result in the L2 kickoff's SMOKE line.

Build first, then click the reload icon on the VoiceType card in chrome://extensions:

```bash
npm test
npm run build
npm run test:e2e
```

## 1. Word segmentation in Chrome (V15)
chrome://extensions, VoiceType, "Inspect views: service worker". In its console paste:

```js
const n = (t) => [...new Intl.Segmenter(undefined, { granularity: 'word' }).segment(t)].filter((s) => s.isWordLike).length;
[n("Hello, world! It's a test."), n('Καλημέρα, τι κάνεις; Είμαι καλά.'), n('Το API του OpenAI κοστίζει 0,006 $ ανά λεπτό.'), n('...!!!')]
```

Expected: `[5, 5, 8, 0]` (the same counts Node gives in `test/unit/platform/segmenter.test.js`).

## 2. Your existing history (before any new dictation)
- Open the settings page (it opens on Home). With sessions in your log from before this build: the "This week" stats show; Time saved, Words, Speaking speed and Per 1,000 words read "Counted from 3.0 on"; Refined by a mode, Cost and Days dictated show real numbers; nothing reads NaN, Infinity or a negative number.
- Days dictated: seven squares Monday first; today is outlined; days still to come are dashed; days you dictated are filled.

## 3. Live update and counting
- Keep the settings tab open on Home. In another tab dictate an English sentence you can count (for example "This is a short test of the word counter", nine words). Back on Home, without reloading: Words this week went up by nine (Default mode, so the count is of what you said).
- Dictate a Greek sentence (for example "Καλημέρα, τι κάνεις σήμερα;", four words, with Greek in your spoken languages or Auto). Words go up by four.
- Open Settings, Usage and data in the same tab: the table already includes both sessions without pressing Refresh.

## 4. Thresholds
- After at least 30 seconds of talking this week, Speaking speed shows "N words per minute" (before that: "Shows after 30 s of talking").
- After 100 words this week, Per 1,000 words shows a cost (before that: "Shows after 100 words").
- Time saved reads "about N min" from one minute up, with "X min talking instead of Y min typing" under it.
- Dictate once in a mode other than Default (for example Email): Refined by a mode goes up by one.

## 5. Empty state and errors
- Settings, Usage and data, Clear history (two clicks). Back on Home without reloading: only "Dictate once to see your stats." shows.

## 6. Look and keyboard
- Light and dark (OS setting): Home is readable on every surface; the day squares are distinguishable in both.
- Narrow the window under about 720 px: the cards stack and nothing scrolls sideways.
- Tab through Home: focus order follows the screen. With a screen reader, or the accessibility pane in DevTools, each day square reads "Monday, dictated", "Tuesday, not dictated" or "Sunday, still to come" (note whether it is read twice; the hover tooltip carries the same text).

## 7. 2.2 and L0 regressions (quick pass)
- Dictate into a textarea (tap and hold the hotkey); the cost shows after "Done"; Today in the popup counts the session; the popup's Open settings reuses the open tab.
