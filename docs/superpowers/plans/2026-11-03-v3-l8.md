# VoiceType 3.2 L8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship command mode, recovery from a stopped worker, the navigated frame fix, forced colours, code health and the release side as 3.2.0.

**Architecture:** An edit is a dictation with a second chord: the selection travels in `START_RECORDING`, the pipeline runs STT then a fixed text-model prompt, and delivery checks that the selection is unchanged before the ladder replaces it. Recovery holds the audio in `chrome.storage.session` during processing and a 5 s ping from the page wakes a new worker. Sessions target a `documentId`. The controller is split first, so the new code lands in smaller files.

**Tech Stack:** Chrome MV3 (minimum Chrome 140), plain JavaScript with JSDoc, esbuild, Vitest with jsdom, Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-05-v3.2-design.md` (V40 to V57). Parents: `docs/superpowers/specs/2026-11-04-v3.1-design.md`, `docs/superpowers/specs/2026-11-03-v3-design.md`. Ledger: `docs/superpowers/plans/2026-11-03-v3-l8-ledger.md`.

**Author:** K. S. Karakostas. Prepared 2026-11-05.

## Global Constraints

- `minimum_chrome_version` stays `"140"`; zero runtime dependencies; no new permission.
- `SETTINGS_VERSION` and the migration routing are untouched.
- Keys never reach content scripts or pages; the offscreen document never handles one.
- The pill stays in a closed Shadow DOM. User data set with `textContent` only. No `innerHTML`.
- Anti-goals of the 3.0, 3.1 and 3.2 specs hold, D12 above all.
- Selected text never reaches a log line, `console`, the history, the usage log or `chrome.storage.local`.
- No em or en dashes anywhere. In files the author is K. S. Karakostas.
- Commit messages carry the change description only: no trailers, no AI attribution. Branch `v3.2`.
- Every task ends with `npm test` green (report `N/N`) and `npm run build` clean. A task marked e2e also runs `npm run test:e2e`.
- One test file: `npx vitest run <path>`. One e2e file: `npx playwright test test/e2e/<file>` after `npm run build`.
- No version bump and no CHANGELOG heading in any task: the controller does both last.
- All subagents run on Opus (spec V22).

## Review Focus

1. The page rewrites the field during the recording, so the same offsets hold different text: the replacement is copied, the field untouched. Test in Task 8.
2. A selection with quotes, newlines, a closing brace, right-to-left text and emoji: `selected_text` round-trips through JSON unchanged. Test in Task 7.
3. Ctrl+Shift+E held on a page that has its own shortcut, with no selection: every keydown, repeats included, reaches the page. Test in Task 8.
4. An edit on a hidden site or in Minimal: the indicator shows and the start status reads. Test in Task 8 (e2e).
5. A worker stopped during an edit's refine: the retry resends the selection, the field gets one replacement, no history entry. Test in Task 9.
