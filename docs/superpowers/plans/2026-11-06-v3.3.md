# VoiceType 3.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Minimal beside the field and bigger, softer default sounds, with a choice of size, sound set and recording colour.

**Architecture:** Three new validated settings. `position.js` gains one pure function for Minimal's place; `Pill` gains one `setLook` call that the controller and the mirror feed; `cues.js` holds the four sets; `pill.css` carries sizes and colours by data attributes on `.vt`.

**Tech Stack:** Plain JavaScript with JSDoc, esbuild, Vitest, Playwright, Web Audio.

**Spec:** `docs/superpowers/specs/2026-11-06-v3.3-design.md`. Tables 3, 4 and 5 hold every size, colour and sound value: copy them from there.

## Global Constraints

- Branch `v3.3`; `minimum_chrome_version` stays 140.
- No new permission, no new runtime dependency, no audio file.
- `settingsVersion` stays 3.
- A status colour never follows `recColor`: `--vt-success`, `--vt-warning`, `--vt-error` are untouched.
- Forced-colours rules stay as V54 has them.
- Run e2e outside the bubblewrap sandbox: Chromium aborts inside it.
- No em or en dash in any document. No AI attribution in any commit.
- The version bump and CHANGELOG come last (Task 7), after K. S. Karakostas's start-sound gate.

Helpers in the test code below (`setup`, `start`, `stop`, `pick`, `click`, `openWith`, `settle`, `deferred`) stand for each test file's own helpers or thin local wrappers: follow what the file has.

## Review Focus

- A field near an edge: Extra large that fits on no side goes to the bottom, never over the text (Task 2).
- A field scrolled away during a recording, then back: the indicator goes to the bottom centre and returns (Task 3).
- `miniSize` or `recColor` saved in another tab during a recording: the live indicator follows, with no error (Task 3).
- A dictation in a cross-origin frame: the indicator and its status stand together in that frame (Task 3).
- The play button pressed twice, or with audio refused: the sets do not stack, and nothing throws (Task 5).
