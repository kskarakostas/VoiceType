## Defects and evidence

- D1 (Task 1): Slate 0.126 / slate-react 0.127: single-line dictation uses `execCommand('insertText')` first (`insert.js` contenteditable ladder); Chrome fires no `beforeinput` for it and slate-react ignores the resulting `input`, so the DOM changes but the model does not; `judge` reads the DOM and reports `'inserted'`; the next keystroke re-renders from the model and the text disappears; nothing was copied. Multi-line (paste first) works. Reproduced 3/3 in a local slate-react page.
- D2 (Tasks 2 and 3): Chromium resets a frame's `activeElement` to `BODY` when focus moves to another frame, so the hold condition (`controller.js` deliver: `deepActiveElement() === bound && !hasFocus()`) never matches and delivery takes the clipboard path. There `navigator.clipboard.writeText` rejects in the unfocused frame, `execCopy` focuses its helper textarea (`insert.js` execCopy) and then refocuses the frame's `BODY`, pulling keyboard focus out of the parent page field. Reproduced for same-origin and cross-origin frames in Chromium 153.
- D3 (Task 4): with a password field focused, the hotkey starts a no-target recording (D12 corner mode), uploads the audio and copies the transcript.
- D5 (Task 5): after the extension is disabled, the orphaned content script still calls `preventDefault` on the chord (`boot.js` onKeyDown) before any liveness check, so Ctrl+Shift+Space never reaches the page until reload.
- D4 (Task 6): typing in the mode editor then clicking a mode row once: the blur save renders synchronously and `renderModes` calls `replaceChildren()`, replacing the button between mousedown and mouseup, so no click fires.
- D7 (Task 6): `chrome.storage` returns object keys sorted, so `custom_<timestamp>` modes list before `default` in the popup and the pill menu after a reopen.
- D8 (Task 6): the popup saves typed or pasted text on change, blur or 800 ms after input; a close with no blur inside 800 ms drops it (no `pagehide` flush).

```js
/**
 * Editors that get the paste rung before `execCommand('insertText')`, single-line text
 * included. Chrome fires no `beforeinput` for that command and slate-react ignores the
 * `input` that follows, so the text reaches Slate's DOM but not its model, and the next
 * keystroke erases it. Slate takes a plain-text paste into its model.
 */
export const PASTE_FIRST_EDITOR_SELECTOR = '[data-slate-editor]';

/**
 * True when el belongs to an editor that must get the paste rung first.
 * @param {Element|null|undefined} el
 * @returns {boolean}
 */
export function isPasteFirstEditor(el) {
  if (!el || el.nodeType !== 1) return false;
  return el.closest(PASTE_FIRST_EDITOR_SELECTOR) !== null;
}
```

### Task 2: The copy fallback never moves focus without document focus

**Files:**
- Modify: `src/content/insert.js`
- Test: `test/unit/content/insert.test.js`

**Interfaces:**
- Produces (amended 2026-09-27 after a Chromium measurement: the pill cancels mousedown, so a click on a frame's pill never gives that frame focus, and a focus-gated fallback would break click-to-copy in frames): `execCopy(text)` no longer creates or focuses a helper textarea. It registers a one-shot capture-phase `copy` listener on the document that calls `event.clipboardData.setData('text/plain', text)`, `event.preventDefault()` and `event.stopImmediatePropagation()`, calls `document.execCommand('copy')`, removes the listener in `finally`, and returns true only when the listener ran and `execCommand` returned true. `copyText` keeps its order (Clipboard API `writeText` first; on rejection or absence, `execCopy`). No `focus()` call and no `activeElement` change anywhere in the copy path. Injectable seams as needed for jsdom (for example `deps.execCommand`).
- Tests: the Review Focus 2 test by name, reworded to "the copy fallback never moves focus": writeText rejects, the fallback copies through the copy event, `document.activeElement` and the selection are unchanged, no element was appended; the fallback returns false when the copy listener never ran; the Clipboard API missing still uses the fallback. Verified in Chromium 153 by the plan writer: the copy event technique copies from an unfocused frame, automatically and on a pill click, without moving focus.

WRITER NOTES

- Written to the amended contract. `copyText` keeps its `deps.execCopy` seam and adds no `deps.execCommand`: `insertText` hands its whole `deps` to `copyText`, and its `deps.execCommand` is already the `insertText` rung, so reusing the name would send the ladder's stand-in to the copy. The tests stub `document.execCommand` instead (jsdom has none, and `afterEach` already deletes it).
- The listener cancels the event before it calls `setData`, so a failed `setData` can never let the page's selection reach the clipboard.
- `deepActiveElement` leaves the `insert.js` import (it is no longer used). The anchor is the post-Task-1 import line.
- Chromium 153 on this task's build, fixtures page, frame dictation, then a click on the page field while it processes. Every run kept page focus and typing landed:
  - Stub 3 s: both frames copied automatically ("The field lost focus. Text copied to clipboard.").
  - Stub 6.5 s: "Could not insert. Click here to copy the text."; a click on the frame's status gave "Copied to clipboard." with the right clipboard.
  - All of this held with and without the clipboard-write grant: grant-independent, but it needs the STOP click's user activation (about 5 s).

```js
describe('copyText', () => {
  const denied = async () => { throw new Error('Document is not focused.'); };

  /**
   * execCommand('copy') as Chrome runs it: without a user gesture it refuses and fires nothing;
   * otherwise a cancelable copy event goes to the focused element (or the body), and the
   * clipboard receives the event's clipboardData when the event was prevented, else the selection.
   */
  function chromeCopy(clipboard, { allowed = true } = {}) {
    return vi.fn((command) => {
      if (command !== 'copy' || !allowed) return false;
      const data = new Map();
      const event = new Event('copy', { bubbles: true, cancelable: true, composed: true });
      event.clipboardData = { setData: (type, value) => data.set(type, value), getData: (type) => data.get(type) ?? '' };
      (document.activeElement ?? document.body).dispatchEvent(event);
      clipboard.text = event.defaultPrevented ? (data.get('text/plain') ?? '') : String(document.getSelection());
      return true;
    });
  }

  it('uses navigator.clipboard.writeText when available', async () => {
    const writeText = vi.fn(async () => {});
    vi.stubGlobal('navigator', { clipboard: { writeText } });
```

```js
 * `execCommand('copy')` with the text supplied by a one-shot `copy` listener instead of a
 * selection, so nothing is focused or selected: a frame without focus copies without pulling
 * keyboard focus out of the page the user is typing in. Chrome runs the command only during a

function execCopy(text) {

  let supplied = false;
  const onCopy = (event) => {
    // Cancelled first, so a failed setData never lets the page's selection reach the clipboard.
```

```js
/**

/** @param {import('@playwright/test').Page|import('@playwright/test').Frame} target */
function frameOf(target) {
  return typeof target.mainFrame === 'function' ? target.mainFrame() : target;
}

/**
 * A session that sees frame's document: an out-of-process frame (another site) has one of its
 * own; a same-process frame is part of its page's session.
 * @param {import('@playwright/test').Frame} frame
 */
async function sessionFor(frame) {
  const page = frame.page();
  const context = page.context();
  if (!frame.parentFrame()) return context.newCDPSession(page);
  try {
    return await context.newCDPSession(frame);
  } catch {
    return context.newCDPSession(page);
  }
}

/**
 * The document node loaded from url; pierce lists same-process frame documents too.
 * @param {any} node CDP DOM.Node
 * @param {string} url
 */
function findDocument(node, url) {
  if (node.nodeName === '#document' && node.documentURL === url) return node;
  const next = [...(node.children ?? []), ...(node.shadowRoots ?? []), ...(node.contentDocument ? [node.contentDocument] : [])];
  for (const child of next) {
    const found = findDocument(child, url);
    if (found) return found;
  }
  return null;
}

/** @param {any} node CDP DOM.Node */
function findPillHost(node) {
  if (node.localName === 'voicetype-host') return node;
  // children only: frame documents (contentDocument) have pills of their own.
  for (const child of node.children ?? []) {
    const found = findPillHost(child);
    if (found) return found;
  }
  return null;
}

/**
 * Where frame's viewport starts in its page's viewport.
 * @param {import('@playwright/test').Frame} frame
 */
async function frameOrigin(frame) {
  if (!frame.parentFrame()) return { x: 0, y: 0 };
  const element = await frame.frameElement();
  try {
    const box = await element.boundingBox();
    const inset = await element.evaluate((el) => {
      const style = getComputedStyle(el);
      return { x: el.clientLeft + parseFloat(style.paddingLeft), y: el.clientTop + parseFloat(style.paddingTop) };
    });
    return { x: box.x + inset.x, y: box.y + inset.y };
  } finally {
    await element.dispose();
  }
}

/**
 * The box (page viewport coordinates) and text of `selector` inside the pill of a page's top
 * document or of one frame.
 * @param {import('@playwright/test').Page|import('@playwright/test').Frame} target
 * @param {string} selector CSS selector inside the pill
 * @returns {Promise<{ x: number, y: number, width: number, height: number, text: string }|null>}
 */
export async function pillQuery(target, selector) {
  const frame = frameOf(target);
  const cdp = await sessionFor(frame);
  try {
    const { root } = await cdp.send('DOM.getDocument', { depth: -1, pierce: true });
    const doc = findDocument(root, frame.url());
    const shadow = doc && findPillHost(doc)?.shadowRoots?.find((r) => r.shadowRootType !== 'user-agent');
    if (!shadow) return null;
    const { nodeId } = await cdp.send('DOM.querySelector', { nodeId: shadow.nodeId, selector });
    if (!nodeId) return null;
    const { object } = await cdp.send('DOM.resolveNode', { nodeId });
    const { result } = await cdp.send('Runtime.callFunctionOn', {
      objectId: object.objectId,
      functionDeclaration: `function () {
        const r = this.getBoundingClientRect();
        return { x: r.left + r.width / 2, y: r.top + r.height / 2, width: r.width, height: r.height, text: this.textContent };
      }`,
      returnByValue: true,
    });
    const origin = await frameOrigin(frame);
    return { ...result.value, x: result.value.x + origin.x, y: result.value.y + origin.y };
  } finally {
    await cdp.detach().catch(() => {});
  }
}

/**
 * Waits until `selector` is rendered inside the pill and returns its box.
 * @param {import('@playwright/test').Page|import('@playwright/test').Frame} target
 * @param {string} selector
 */
export async function waitForPill(target, selector, timeout = 10_000) {
  let box = null;
  await expect.poll(async () => {
    box = await pillQuery(target, selector);
    return Boolean(box && box.width > 0 && box.height > 0);
  }, { timeout, message: `pill element ${selector}` }).toBe(true);
  return box;
}

 * @param {import('@playwright/test').Page|import('@playwright/test').Frame} target

export async function pillStatus(target) {

}

/**
 * A real mouse click, so the pill's mousedown handler keeps focus in the field.
 * @param {import('@playwright/test').Page|import('@playwright/test').Frame} target
 * @param {string} selector
 */
export async function clickPill(target, selector) {
  const frame = frameOf(target);
  const page = frame.page();
  // Idle, the pill is a dot: its controls sit in a zero-width, clipped bar until hover expands it.
  const body = await waitForPill(frame, '.body');
  await page.mouse.move(body.x, body.y);
  // Wait until the bar has expanded and stopped animating: two equal, non-zero widths in a row.
  let lastWidth = -1;

    const settled = width > 0 && width === lastWidth;
    lastWidth = width;
    return settled;
  }, { message: 'pill bar expanded' }).toBe(true);
  const box = await waitForPill(frame, selector);
  await page.mouse.click(box.x, box.y);
}
```

```js
const CUSTOM_MODE_KEY = /^custom_(\d+)$/;

/**
 * Mode keys in display order: the built-ins present, in `BUILTIN_MODES` order; then custom
 * modes (`custom_<n>`, n being the creation time) by ascending n; then any other own keys in
 * ascending string order. chrome.storage hands objects back with their keys sorted, so the
 * stored order would list `custom_...` above `default`.
 * @param {Record<string, Mode>} modes
 * @returns {string[]}
 */
export function orderedModeKeys(modes) {
  const keys = isObject(modes) ? Object.keys(modes) : [];
  const builtIn = Object.keys(BUILTIN_MODES).filter((key) => keys.includes(key));
  const custom = [];
  const other = [];
  for (const key of keys) {
    if (Object.hasOwn(BUILTIN_MODES, key)) continue;
    const match = CUSTOM_MODE_KEY.exec(key);
    if (match) custom.push({ key, n: Number(match[1]) });
    else other.push(key);
  }
  custom.sort((a, b) => a.n - b.n || (a.key < b.key ? -1 : 1));
  return [...builtIn, ...custom.map(({ key }) => key), ...other.sort()];
}
```
