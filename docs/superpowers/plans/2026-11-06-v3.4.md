# VoiceType 3.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Settings page with dividers, the Mic and cursor icon, a compact popup, and a pick of the last 5 dictations.

**Architecture:** The seven settings sections become parts of one routed section, with their hashes kept as jump targets. Icons render from committed SVGs by a dev script. The popup's markup and CSS are rewritten in place; a new small module owns the recent list.

**Tech Stack:** Plain JavaScript with JSDoc, esbuild, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-06-v3.4-design.md`.

## Global Constraints

- Branch `v3.4`; `minimum_chrome_version` stays 140.
- No new permission, no new runtime dependency, no stored field.
- Every hash that works in 3.3 keeps working.
- No em or en dash in any document. No AI attribution in any commit.
- Run e2e outside the bubblewrap sandbox: Chromium aborts inside it.
- The screenshots, the CHANGELOG and the bump to 3.4.0 come last (Task 6), after K. S. Karakostas's manual rows.

Helpers in the test code below (`setup`, `open`, `click`, `settle`) stand for each test file's own helpers or thin local wrappers: follow what the file has.

## Review Focus

- A jump with unsaved typing: a key typed in Provider, then a sidebar jump, keeps its value and its typing save (Task 1).
- The last part on a short window: a link to Usage and data that cannot scroll to the top still moves focus there (Task 1).
- A dictation with line breaks, or thousands of characters: one line in the list, the whole text copied (Task 4).
- The clipboard refused while copying from the list: "Could not copy.", and the list stays (Task 4).
- A long internationalised site name: one line, full name in `title`, Hide pill and the mode still reachable (Task 3).

```js
const entries = (n) => Array.from({ length: n }, (_, i) => ({ text: `dictation ${i}` }));
it('stays closed until the arrow, and shows no text', () => {
  const { recent, list, toggle } = setup();

  expect(list.textContent).toBe('');

it('opens the newest 5', () => {
  const { recent, list, toggle } = setup();
  recent.render(entries(8), true);
  toggle.click();
  expect([...list.querySelectorAll('button')].map((b) => b.textContent)).toEqual(entries(5).map((e) => e.text));

it('shows one line and copies the whole text', async () => {
  const { recent, list, toggle, copy } = setup();
  const text = `first line\nsecond line ${'x'.repeat(5000)}`;
  recent.render([{ text }, { text: 'b' }], true);
  toggle.click();
  const row = list.querySelector('button');
  expect(row.textContent).toBe('first line');
  row.click();
  await settle();
  expect(copy).toHaveBeenCalledWith(text);
});
it('stays open after a copy, says so, and says so when the copy fails', async () => {
  const { recent, list, toggle, copy, toast } = setup();
  recent.render(entries(2), true);
  toggle.click();
  list.querySelector('button').click();
  await settle();
  expect(toast).toHaveBeenLastCalledWith('Copied to clipboard.', 'success');
  copy.mockRejectedValueOnce(new Error('refused'));
  list.querySelector('button').click();
  await settle();
  expect(toast).toHaveBeenLastCalledWith('Could not copy.', 'error');
  expect(list.hidden).toBe(false);
});
it('hides the arrow below 2 entries, and with history off', () => {
  const { recent, toggle } = setup();
  recent.render(entries(1), true);
  expect(toggle.hidden).toBe(true);
  recent.render(entries(3), false);
  expect(toggle.hidden).toBe(true);
});
it('a clear empties an open list', () => {
  const { recent, list, toggle } = setup();
  recent.render(entries(3), true);
  toggle.click();
  recent.render([], true);
  expect(list.hidden).toBe(true);
  expect(list.textContent).toBe('');
  expect(toggle.getAttribute('aria-expanded')).toBe('false');
});
```
