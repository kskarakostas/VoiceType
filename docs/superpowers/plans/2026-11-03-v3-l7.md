# VoiceType 3.1 L7 Post-release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Translate setting, history with Undo AI edit, onboarding, release engineering and six deferred fixes as 3.1.0.

**Architecture:** History is a small queued store over `chrome.storage.session` in the worker, written from `dictate.js` and read over three new messages. Every page surface reads it through the worker; a content script gets only its own site's newest entry. `pill.js` is split first, so the menu work lands in a smaller file. Everything else is a local change.

**Tech Stack:** Chrome MV3 (minimum Chrome 140), plain JavaScript with JSDoc, esbuild, Vitest with jsdom, Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-04-v3.1-design.md` (V24 to V39). Parent: `docs/superpowers/specs/2026-11-03-v3-design.md`. Ledger: `docs/superpowers/plans/2026-11-03-v3-l7-ledger.md`.

**Author:** K. S. Karakostas. Prepared 2026-11-04.

## Global Constraints

- `minimum_chrome_version` stays `"140"`; zero runtime dependencies; no new permission.
- `SETTINGS_VERSION` and the migration routing are untouched.
- Keys never reach content scripts or pages; the offscreen document never handles one.
- The pill stays in a closed Shadow DOM. User data set with `textContent` only. No `innerHTML`.
- Anti-goals of the 3.0 spec and of 3.1 spec section 1 hold, D12 above all.
- No em or en dashes anywhere. In files the author is K. S. Karakostas.
- Commit messages carry the change description only: no trailers, no AI attribution. Branch `v3.1`.
- Every task ends with `npm test` green (report `N/N`) and `npm run build` clean. A task marked e2e also runs `npm run test:e2e`.
- One test file: `npx vitest run <path>`. One e2e file: `npx playwright test test/e2e/<file>` after `npm run build`.
- No version bump and no CHANGELOG heading in any task: the controller does both last.
- All subagents run on Opus (spec V22).

## Review Focus

1. Insert last with a password field focused: nothing is typed there; the text goes to the clipboard, as with no field. Test in Task 8.
2. Undo AI edit after the user typed before the inserted text, so the offsets moved: the field is untouched and the raw text is copied. Test in Task 8.
3. Two dictations finishing together, or a worker restart between adds: no entry lost, cap 20 held. Test in Task 6.
4. History text containing `<img src=x onerror=...>` on the History page: shown as text. Test in Task 7.
5. An update or a browser start with a welcome route: no tab opens; a settings tab already on `#welcome` is reused by Open settings. Test in Task 9.
