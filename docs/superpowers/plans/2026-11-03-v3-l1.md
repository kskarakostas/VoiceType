# VoiceType 3.0 L1 Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Count the words of every dictation into the usage log and show this week's stats on the settings page's Home.

**Architecture:** `src/background/usage.js` gains three bucket fields (`words`, `wordSeconds`, `wordCost`), a `countWords` helper (V15) and a Monday-first week in `summarize` (V16); `dictate.js` passes the word count with each usage entry. A pure module `src/options/home-stats.js` turns the `GET_USAGE` summary into every number and string Home shows; `src/options/sections/home.js` renders it and reloads on a usage change or when the tab becomes visible, and the Usage and data table gets the same reload.

**Tech Stack:** Chrome MV3 (minimum Chrome 140), plain JavaScript with JSDoc, esbuild, Vitest with jsdom, Playwright with bundled Chromium.

**Spec:** `docs/superpowers/specs/2026-11-03-v3-design.md` (sections 2 V14 to V16, 3, 6.2). Master plan: `docs/superpowers/plans/2026-11-03-v3-master.md` (L1 row). Previous lane: `docs/superpowers/plans/2026-11-03-v3-l0-ledger.md` (deferred for L1: the usage table goes stale in an open tab). Step A evidence and decisions: `docs/superpowers/plans/2026-11-03-v3-l1-ledger.md`.

**Author:** K. S. Karakostas. Prepared 2026-11-03.

### Task 2: Pure Home stats

**Files:**
- Create: `src/options/home-stats.js`
- Test: `test/unit/options/home-stats.test.js`

**Interfaces:**
- Consumes: the `summarize` reply from Task 1 (`today`, `last7Days`, `thisWeek`, `total`, `week`), through `GET_USAGE`; `formatCost` from `src/shared/pricing.js`.
- Produces (`src/options/home-stats.js`), all pure:
  - `TYPING_WPM = 40` (V14), `MIN_SPEED_SECONDS = 30`, `MIN_COST_WORDS = 100`.
  - `typingMinutes(words: number): number` = `words / 40`.
  - `talkingMinutes(wordSeconds: number): number` = `wordSeconds / 60`.
  - `minutesSaved(words: number, wordSeconds: number): number` = `max(0, typingMinutes - talkingMinutes)`.
  - `speakingWpm(words: number, wordSeconds: number): number|null` = `words / wordSeconds * 60` when `wordSeconds >= 30`, else `null`.
  - `costPerThousandWords(wordCost: number, words: number): number|null` = `wordCost / words * 1000` when `words >= 100`, else `null`.
  - `refinedSessions(modes: Record<string, number>): number`: sum of every own count except key `default`.
  - `formatMinutes(minutes: number): string`: `'0 min'` for 0; `'under 1 min'` for more than 0 and under 1; else rounded `'N min'`; from 60 up `'H h M min'` (`'1 h 0 min'`, `'2 h 5 min'`).
  - `formatCount(n: number): string`: `new Intl.NumberFormat('en-US').format(Math.round(n))` (`1234` gives `'1,234'`).
  - `homeView(summary: unknown): HomeView`, the one function the section calls:

```js
/**
 * @typedef {{
 *   state: 'error'|'empty'|'noWords'|'full',
 *   saved: string,          // 'about 12 min', or 'under 1 min' / '0 min' without "about"
 *   savedDetail: string,    // '3 min talking instead of 15 min typing'
 *   wordsWeek: string,      // '1,234'
 *   wordsTotal: string,     // '5,678'
 *   speed: string,          // '142 words per minute' or GATED_SPEED
 *   refined: string,        // '4 of 9 sessions' or 'No sessions yet'
 *   costWeek: string,       // formatCost(thisWeek.estimatedCost)
 *   costPer1k: string,      // formatCost(...) or GATED_COST
 *   days: Array<{ label: string, name: string, state: 'dictated'|'missed'|'upcoming', today: boolean }>,
 *   daysCount: string,      // '3 of 7 days'
 * }} HomeView
 */
```

Rules for `homeView`:
- Every bucket number is read as `Number.isFinite(v) && v > 0 ? v : 0`; a missing bucket is all zeros; a `week` that is not seven days with a `todayIndex` 0 to 6 is replaced by seven `missed` days with no today.
- `state`: `'error'` when `summary` is not an object or has no object `total`; `'empty'` when `total.sessions` is 0; `'noWords'` when `total.words` is 0; else `'full'`.
- In `noWords`, `saved`, `savedDetail`, `wordsWeek`, `wordsTotal`, `speed` and `costPer1k` are the string `NOT_COUNTED = 'Counted from 3.0 on'` (decision above); the rest render.
- `saved`: `formatMinutes(minutesSaved(...))`, prefixed `'about '` only when the minutes are 1 or more. `savedDetail`: `` `${formatMinutes(talkingMinutes)} talking instead of ${formatMinutes(typingMinutes)} typing` ``. Both from `thisWeek`.
- `GATED_SPEED = 'Shows after 30 s of talking'`; `speed` otherwise `` `${Math.round(wpm)} words per minute` ``. `GATED_COST = 'Shows after 100 words'`. Both from `thisWeek`.
- `refined`: `` `${refinedSessions(thisWeek.modes)} of ${thisWeek.sessions} sessions` ``; `'No sessions yet'` when `thisWeek.sessions` is 0.
- `days`: labels `Mon Tue Wed Thu Fri Sat Sun`, names `Monday` to `Sunday`; index above `todayIndex` is `'upcoming'`, else `'dictated'` when `sessions > 0`, else `'missed'`; `today` true at `todayIndex`. `daysCount`: `` `${dictated} of 7 days` ``.
