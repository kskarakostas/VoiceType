# VoiceType 3.0 lane L2 smoke checklist (for K. S. Karakostas)

Branch `v3`, still version 2.2.0 (only L6 bumps the version). Checks the L2 deliverables: the Dictionary page and CSV import and export. Needs Chrome 140 or newer and one working key. Note each item as pass, fail (with the exact on-screen text) or n/a, and put the result in the L3 kickoff's SMOKE line.

Build first, then click the reload icon on the VoiceType card in chrome://extensions:

```bash
npm test
npm run build
npm run test:e2e
```

## 1. Your existing terms
- Open the settings page, Dictionary. Your vocabulary from the old field shows as chips in the All languages card; the count reads "N of 100 terms".
- Settings, Speech: the Vocabulary field is gone; the line under the languages links to the Dictionary. Spoken languages still work.

## 2. Adding terms
- In All languages type `Palowise` and press Enter: a chip appears, the field empties.
- Type `Alpha, Beta` and press Enter: two chips.
- Type `palowise` and press Enter: refused with "Already in All languages"; the text stays.
- Add language, Greek: a Greek card appears under All languages with its field focused. Type `Palowise` there: "Already in All languages". Type `Νόηση`, Enter: a chip.
- Type a 65-character term: "Terms can have at most 64 characters".
- Paste a list of three lines (for example a spreadsheet column) into the field: it reads as `a, b, c`; Enter adds three chips. Paste one line: it stays as pasted.
- Type `Gamma` with no Enter, click somewhere else: the chip appears. Type `Delta` with no Enter, wait a second, close the tab, reopen Dictionary: `Delta` is there.

## 3. Removing
- Remove a chip with the mouse, then one with the keyboard (Tab to its x, Enter): focus lands on the next chip.
- Double-click a chip's x, and hold Enter on one: each removes one term only.
- Remove the last term of Greek: the card stays, empty. Remove group on it: the first click asks "Click again to remove this group and its terms", the second removes the card. Greek is offered in Add language again.
- Wait three seconds after the first click: the button goes back to Remove group.

## 4. Export
- Export CSV: `voicetype-dictionary.csv` downloads.
- Open it in Excel (or LibreOffice): Greek shows correctly, not as mojibake. Note whether your Excel shows two columns or one.
- Without changing the dictionary, Import CSV and pick that file: "Nothing new: all N terms are already in the dictionary."

## 5. Import
- A text file with one term per line: the terms land in All languages.
- A file with a line `xx,term` under a `language,term` header: "Line N: unknown language "xx". Nothing was imported."
- A file that would pass 100 terms: "This import would go over the 100 term limit by N. Nothing was imported."
- In Excel, add a row, save as "CSV UTF-8", import it: the new term lands in its group. Save the same sheet as plain "CSV (Comma delimited)" with a Greek term in it, import it: "This file is not UTF-8. Save it as CSV UTF-8 and try again. Nothing was imported."
- In Excel, save as "Unicode Text" (tab separated), import it: "Line 1: the term contains a tab. Nothing was imported."
- Pick the same file twice in a row: the second pick also reports.

## 6. Live data and the provider
- Keep the Dictionary tab open. In a second settings tab add a term. The first tab shows it without a reload; text you were typing there stays.
- Leave the Dictionary tab idle for a minute or more so the service worker sleeps. Type a term with no Enter, wait a second, close the tab with Ctrl+W, reopen: the term is there.
- Dictate a sentence with a term from the Greek group while speaking English: the term is sent all the same (V4, V17). Compare with the same sentence after removing the term.

## 7. Look and keyboard
- Light and dark (OS setting): chips, cards and error text are readable.
- Narrow the window under about 720 px: cards stack; a 64-character term wraps inside its chip and nothing scrolls sideways.
- Tab through the page: focus order follows the screen, every chip's x shows a focus ring and is named "Remove <term>" in the accessibility pane.

## 8. 2.2, L0 and L1 regressions (quick pass)
- Dictate into a textarea; the cost shows after Done; Today in the popup counts the session; Home updates.
- Reset to defaults on Settings, Usage and data keeps the dictionary.
