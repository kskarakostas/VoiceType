# VoiceType 3.4 smoke checklist (for K. S. Karakostas)

Branch `v3.4`, version still 3.3.0: the bump to 3.4.0, the CHANGELOG and the screenshots come after your rows (V78). Covers what 3.4 changed: the one Settings page with jump links, the Mic and cursor icon, the compact popup, and the list of recent dictations. Then the manual rows still open from the 3.3 list and the older lists. Spec: `docs/superpowers/specs/2026-11-06-v3.4-design.md`.

The Run column says who has it: **H** a harness ran it (result in the row), **M** a person has to. Your part is every M row. Fill Result with pass, fail (with the exact on-screen text or what you saw) or n/a. Needs a working key and a microphone, for the dictations rows 3.3 and 3.4 use.

Order (Task 6 of `docs/superpowers/plans/2026-11-06-v3.4.md`): Atlas hands you the M rows and stops until each has a result, sections in order. There is no gate section; the spec names none.

Build, then reload VoiceType on `chrome://extensions` and reload any open page:

```bash
npm run build
```

Fixture pages, in a second terminal:

```bash
node test/fixtures/serve.mjs
```

`http://localhost:8765/fields.html` has a text field `#text` and a textarea `#ta`. The dictation hotkey is Ctrl+Shift+Space. Pin the VoiceType icon from the puzzle piece menu to open the popup. For light and dark, switch the OS between its light and dark setting (or Chrome's theme) and reload the page.
