# VoiceType 2.1.1 smoke addendum (Task 7, for K. S. Karakostas)

Branch `fix-2.1.1`, version 2.1.1. Re-checks only the 2.1.1 fixes; everything else was covered for 2.1.0 by `docs/superpowers/plans/2026-09-27-phase-1-smoke-checklist.md` and the automated smoke of 2026-09-27. Needs Chrome 140 or newer, a microphone and one working key.

Build first:

```bash
npm install
npm test
npm run build
npx playwright install --no-shell chromium   # once
npm run test:e2e
```

`npm run test:e2e` now also runs `test/e2e/frames.spec.js`, the frame hold of section 2 with a stubbed provider.

Load `dist/` unpacked (chrome://extensions, Developer mode, Load unpacked), or click the reload icon on the VoiceType card if 2.1.0 is loaded from the same folder. The popup's About section shows "Version 2.1.1". Serve the fixtures in a second terminal with `node test/fixtures/serve.mjs` and open `http://localhost:8765/fields.html` (on `localhost`, so that its cross-origin frame loads from `127.0.0.1`).

Note each item as pass, fail (with the exact on-screen text) or n/a.

## 1. Slate single-line dictation (Task 1)
Use Discord's message box in a server or direct message where a stray message does no harm, or another Slate editor such as the rich text example at https://www.slatejs.org/examples/richtext. Do not press Enter in Discord.
- Type "Hello ", then dictate one short sentence in Default mode. The sentence appears once after "Hello " and the pill shows "Done" with the cost.
- Type one more letter. The dictated sentence stays (2.1.0 wiped it at this point).
- Press Home (a fresh caret, not right after your own typing: Slate's own history merges an insert into the preceding typing at the same caret), dictate another sentence and press Ctrl+Z once right away. Only that dictation disappears.
- Email mode (several paragraphs) in the same editor: the text appears once, with its paragraphs.
- Regression: one single-line dictation each in a Lexical editor (a facebook.com post or comment box) and a ProseMirror editor (the claude.ai prompt box). Each is inserted once, and one Ctrl+Z removes it.

## 2. Frames keep the page's focus (Tasks 2 and 3)
On fields.html:
- Click into the cross-origin frame's textarea, click REC on its pill, speak, click REC again, and while it processes click into the page's textarea and start typing. Keep typing until the result has arrived. Every letter lands in the page's textarea and the cursor never leaves it; the page's textarea never receives the dictated text; the frame's pill shows "Return to the field to insert, or click here to copy.".
- Click back into the frame's textarea. The dictated text is inserted there once.
- Repeat both items with the same-origin frame's textarea.
- Repeat once more, and this time click the held status on the frame's pill instead of the frame's textarea. Expected: "Copied to clipboard."; type a letter and it lands in the page's textarea (the click did not move the cursor); Ctrl+V pastes the text; it lands in the frame's textarea at most once. If the pill shows "Copy failed. Click here to try again." instead, note it, click into the frame's textarea and click the status again: it must copy.
- Focus moved within the page: start in the page's textarea, and while it processes click into the page's text input. The text input stays untouched and the pill shows "The field lost focus. Text copied to clipboard."; Ctrl+V pastes the text.
- A real site with an editor inside an iframe and a text field outside it (for example a TinyMCE or CKEditor 4 demo page with a search box): dictate into the editor, click the outside field while it processes and type. The outside field keeps the cursor; clicking back into the editor inserts the text once.

## 3. Password fields (Task 4)
- fields.html: click into the password field and tap Ctrl+Shift+Space, then hold it for 2 s. Each time nothing records (no microphone indicator in the system tray or menu bar, no permission tab) and the pill shows "VoiceType does not record in password fields." at the bottom right corner. The sessions count in the popup's Usage section does not change.
- In DevTools add `autocomplete="current-password"` to the text input, focus it and tap the hotkey: the same notice, nothing records.
- A real login page, for example https://github.com/login: the same in its password field. In its username field the hotkey still records.
- REC on a frame's pill without the focus: dictate into the cross-origin frame's textarea and, while its pill still shows "Done" (about 2 s), click into the page's password field, then hover the frame's pill and click REC. The frame's pill shows "Click into the field you want to dictate into, then press REC.", nothing records (no microphone indicator) and the password field keeps the cursor. Once that status is gone the frame's pill hides.
- A pending copy status is kept. This needs a click-to-copy status on the page itself, which only a failed copy shows. Set Silence auto-stop (popup, Recording) to 2 s. On fields.html click the page background so that no field has focus, tap the hotkey, speak for about 6 s, stop speaking and at once click the browser's address bar; stay there until the result has arrived (about 5 s). Then click into the page's password field. If the pill shows "Could not insert. Click here to copy the text.": press the hotkey there. Nothing records and that status stays as it was. Click it: "Copied to clipboard.", and Ctrl+V in the textarea pastes the text. Press the hotkey in the password field again: now "VoiceType does not record in password fields.". If the pill showed "Copied to clipboard." instead, the copy worked without the page's focus: note n/a (the controller unit tests cover this case). Set Silence auto-stop back to Off.

## 4. A disabled VoiceType lets the hotkey through (Task 5)
- On fields.html open DevTools, Console (context "top") and run `document.addEventListener('keydown', (e) => { if (e.code === 'Space') console.log('page got Space, prevented:', e.defaultPrevented); })`. While VoiceType is on, its hotkey never reaches this listener.
- Turn VoiceType off on chrome://extensions. Back in the fixtures tab, without reloading, click the page background, then click into the textarea and note whether a pill appears on it (known: it may, until the page is reloaded). Press Ctrl+Shift+Space. The console logs "page got Space, prevented: false" and a pill still on screen shows "VoiceType was updated. Reload this page.". Press the chord twice more: each press is logged the same way (2.1.0 swallowed it until the page was reloaded).
- After the notice, click into the page's text input: no new pill appears on it (the notice stays where it is); the chord pressed there still reaches the page (logged as above).
- Turn VoiceType on again and reload the page: the hotkey records again.

## 5. Popup (Task 6)
- Mode order: Add mode, name it "Zeta smoke", click "Create mode"; then Add mode "Alpha smoke" and "Create mode". Close the popup and reopen it. The list reads Default, Email, Translate, Instruct, Zeta smoke, Alpha smoke: built-ins first, then your modes in the order you created them. Open the pill menu on fields.html: the same order.
- First click after typing: make Default the active mode. Open Zeta smoke's editor, type a few words into its prompt and, without pausing, click Email in the mode list once. That one click makes Email active (check mark, toast "Mode: Email").
- Esc right after pasting a key: copy the working key of the selected provider (OpenAI or Gemini; the popup shows that provider's key row), click Clear on that key (the status says "Add API key"), paste the key into the key field and press Esc within half a second. The popup closes. Reopen it: the key field shows the masked key ending "(saved)" and the status says Ready.
- The same for the vocabulary (type a term, press Esc at once, reopen: the term is listed) and for a mode prompt (type words into Zeta smoke's prompt, press Esc at once, reopen its editor: the words are there).
- Observation, does not gate the tag: Clear the key again. Paste a key, then click on the page so the popup closes. Reopen and note whether the key was saved. Esc right after pasting is the supported path; report the result either way. If the key was not saved, paste it again and press Esc.
- Delete Zeta smoke and Alpha smoke and make Default active again.
