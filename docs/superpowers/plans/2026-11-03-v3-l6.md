## Decisions this plan applies

K. S. Karakostas, 2026-11-04: try the popover host; if it does not hold up, stop and ask before dropping it.

PROPOSED (controller, within the spec):
- The raise has its own 250 ms interval. The existing clock runs while recording only, and the raise also has to run through processing and statuses.
- Raising ends when the pill has nothing to show, and the host then leaves the top layer (`hidePopover()`). An idle pill behaves as in 2.2. Left open, an idle pill over a modal would be a dead control: visible, inert.
- Frame 0's pill raises the mirror right after itself, so the mirror stays on top of a frame 0 status, as the L5 ruling on host order requires.
- Under a modal the host is inert (spike item 4). A status is seen and cannot be clicked; the Stop button likewise. The hotkey still works. Accepted, documented in the README.
- A sticky status keeps the interval running until it ends (four raises a second, an orphan notice until reload). Accepted: about 0.017 ms each.

## Review Focus

1. Pointer held on Stop across a raise: mouse down, 600 ms, mouse up must still stop the recording.
2. Keyboard focus on a pill button across a raise: Enter must still act on it.
3. An open menu scrolled during a recording: raises must not reset its scroll. If they do, stop raising while the menu is open and record the ruling.
4. A CSS animation across raises: `vt-pulse` must not restart every 250 ms.
5. After the status ends with a modal open: the host is no longer `:popover-open`.

- [ ] **Step 3: Implement**

In `pill.js`:
- `export const RAISE_MS = 250;` with a comment saying why a timer: a page gives no event when it opens a dialog.
- `mount()`: `host.setAttribute('popover', 'manual');` before the host is appended. `HOST_CSS` and `:host` stay: `all: initial !important` and `display: block !important` beat the UA rules for `[popover]`, so the closed host still paints at its place with no top layer.
- `mount()` adds `doc.addEventListener('fullscreenchange', this.#onFullscreen, true)`, `destroy()` removes it. `#onFullscreen` raises only while the raise timer runs.
- `raise()` (public): no-op with no host; in one `try`, `hidePopover()` then `showPopover()`; the `catch` comment says that a page can take the host out or refuse the show, and z-index still holds against everything but the top layer. After the `try`, `this.#handlers.onRaised?.()`.
- `#syncRaising()`: wanted is `this.#shown && this.#hasContent()`. Rising edge: `raise()` then `setInterval(() => this.raise(), RAISE_MS)`. Falling edge: `clearInterval`, then `hidePopover()` in its own `try`. Called at the top of `#place` (every path after `show`, `reposition`, a state or status change) and from `hide()`. `destroy()` clears the timer.

In `mirror.js`: `raise() { pill?.raise(); }`.

In `boot.js`: frame 0's and every frame's pill gets `onRaised: () => { mirror.raise(); }`, with a comment: the later raise paints on top, so no status hides the mirror.
